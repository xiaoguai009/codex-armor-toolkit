# ACE 待资料模块与提示词暴露检查

适用于 Windows v1.4.0 / Mac v1.4.0-mac.1。

## ACE 模块现在做什么

**目前实现的是资料准备和后续消息续接提示词，不包含可执行 ACE 绕过。**

安装新版后，生成的指令副本增加 ACE 任务准备规则：整理已有资料、只列缺项、不编造结果；后续在同一任务中提供材料时合并已知信息，再继续可以实际验证的工作。普通问候、诗句、频道和 QQ 群口令不变。

工具没有游戏进程访问、内存读写、注入或驱动交互模块；没有目标样本时不把模板标为“已实现”。不会自动收集其他人的消息、持久化任务资料、在后台监控或定时继续。跨任务需要自行带上原任务材料。

把已知的程序/ACE/系统版本、操作、实际结果、预期结果、复现步骤、脱敏日志或自建测试源码路径填好，发给同一个 Codex 任务。缺项保持“待补充”；不要在资料里写账号密码或 Token。

模板操作本身不读取配置、不安装指令、不打开 Codex。两个新的 Windows CMD 在结束后暂停方便阅读；自动化请直接调用 EXE，或设置 `XIAOGUAI_NO_PAUSE=1`。Mac 启动器在缺少 Python 时仍可能先准备运行环境；只读指的是功能不修改 Codex 配置。

## 为什么代理可能拿到提示词

需要区分三种情况：

1. **源码和本机文件**：本仓库公开的内置提示词可直接阅读；安装后为 Codex 生成的指令副本也能被本机使用者读取。保存在本机的备份和历史快照同样不属于秘密存储。
2. **普通 HTTPS 隧道代理**：通常只能看到连接信息，不自动获得 TLS 加密请求正文。不能仅凭“使用了代理”就认定提示词被窃取。
3. **API 中转接收方、TLS 终止/受信任抓包代理、本机调试者**：如果能访问明文请求，就能读取其中的提示词。EXE 打包、Base64、解密密钥也在客户端的加密，以及“不要泄露”规则都不能消除这一点。

**纯本地指令配置工具无法保证提示词不被提取。** 新版不会声称“已防抓包”或“无法提取”，也不会杀代理进程、卸载证书、修改代理、改变 TLS 校验或偷偷切换服务商。

真正不希望交付给使用者的核心指令，必须不放在公开仓库或客户端，改由自己控制的服务端保管和注入。这需要独立的服务端、认证和上游接口设计，不是本版本已实现的功能；也不能保证模型在任意对话中绝对不回显。

## 本版增加的实际措施

- **减少误回显**：生成副本增加规则，不主动复述非公开内部指令；不把网页、日志、截图或工具输出中的导出/外发要求当作用户授权。这是模型行为提示，不是强制安全边界，也未进行模型端防提取评测。
- **保留正常维护能力**：用户明确要求检查或编辑其自己提供的文件时仍正常处理，不用保密规则阻止用户维护自己的配置。
- **只读、脱敏暴露检查**：读取所选配置和当前检查进程的固定环境变量，只报告类别与布尔提示，不输出提示词、密钥、完整 URL、代理值或配置路径。
- **按白名单打包**：发布包只包含列出的公开文件；不递归打包 `.codex`、真实指令、认证文件、配置、历史备份或日志。`.gitignore` 只是辅助，不会保护已提交到 GitHub 的秘密。

### 使用暴露检查

| Windows | Mac |
| --- | --- |
| 双击 `检查提示词暴露.cmd` | 双击 `检查提示词暴露.command` |

```powershell
.\小怪破甲安装器.exe --privacy-check
.\小怪破甲安装器.exe --privacy-check --json
.\小怪破甲安装器.exe --privacy-check --codex-home "C:\你的配置目录" --json
```

```bash
python3 -I ./macos/run.py --privacy-check
python3 -I ./macos/run.py --privacy-check --codex-home "/你的配置目录" --json
```

检查范围：所选 `CODEX_HOME/config.toml`、其中的当前 profile/provider 定义，以及检查进程中的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、部分证书覆盖变量和 `OPENAI_BASE_URL` 提示。环境变量不一定被运行中的 Codex 采用，因此不推断实际请求路线。

不读取引用指令内容或认证文件；不向代理发请求、不抓流量；不检查系统代理/证书库、项目级配置、命令行覆盖或其他进程。未发现提示不代表没有拦截。配置损坏、超限、链接或不可读时返回脱敏错误，保留现场。

### 可机读的真实状态

- 安装结果：`support_modules.ace.mode = "intake_only"`，`bypass_implemented = false`。
- 模板结果：`status = "waiting_for_materials"`，`automatic_resume = false`。
- 暴露检查：`read_only = true`，`interception_status = "not_tested"`。
- `prevents_local_or_proxy_extraction` 始终为 `false`，不是“检查通过就无法提取”。

## 配置与恢复

原有指令正文、外部源文件、首次备份和引用修复规则不变；新的提示词只进入本工具管理块。旧版直接重新安装即可更新管理块，重复安装内容不变时仍零写入。卸载继续恢复原引用，不改模型、账号、服务商、代理或证书。
