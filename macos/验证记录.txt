共享配置入口：1.4.0

一、发行范围

Mac 独立 ZIP，提供安装、卸载、状态、ACE 资料模板、提示词暴露检查五个 .command 入口。
不包含 Windows CMD/EXE，不是 .app 安装器。
优先使用已有 Python 3.11+；没有合格解释器时，首次下载固定版本运行时。
适配目标为 Apple Silicon / Intel。Codex 自身的系统要求另行判断。

三、平台与打包检查

Shell 测试在 Windows MSYS GNU Bash 5.2.37 执行。
脚本按 macOS Bash 3.2 语法编写；本轮没有在 Bash 3.2 或 Mac 实机执行。
新增资料模板和暴露检查复用 Windows 的共享模块，均经过 Mac 平台模拟测试。
非 Mac 系统在写配置前停止；两项新只读功能不会创建或修改 Codex 配置。
Mac 启动器在缺少 Python 时仍可能先准备运行环境；只读不意味着不准备运行时。

Mac 打包器检查显式公开文件白名单、UTF-8/LF、Unix 0755 权限、CRC 和成员内容。
新增模块、五个启动入口、使用说明和适用的测试子集均进入包内。
发布后另行回读安装包并运行解压后的测试；最终 ZIP 的 SHA256 见包外 SHA256SUMS.txt。
