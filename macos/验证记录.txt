一、发行范围

本版是独立 Mac ZIP，提供安装、卸载和状态查看三个 .command 入口。
不包含 Windows CMD/EXE，不是 .app 安装器。
优先使用已有 Python 3.11+；没有合格解释器时，首次联网下载固定版本运行时。
适配目标为 Apple Silicon 和 Intel；Codex 自身的系统要求另行判断。

三、验证内容

- 安装、状态、恢复、精确问候/口令，以及原引用和备份保留。
- CODEX_HOME 和 --codex-home 选择、中文/空格/美元符号路径、隔离模式。
- 非 Mac 平台在写配置前拒绝；打开 Codex 成功、失败、超时均以模拟调用验证。
- Python 发现顺序、版本检查、显式解释器失败、不污染 JSON stdout、退出码。
- 下载 SHA256 校验先于解压及执行、架构/Rosetta/最低系统版本选择。
- 已有缓存复用、损坏缓存保留、锁等待、失败清理和链接目录拒绝。
- 运行时发布瞬间出现目录、文件、链接时保持已有目标不变。
- Darwin renamex_np 的参数、RENAME_EXCL=4 和 errno 处理使用 mock 验证。
- Mac ZIP 独立文件名、白名单、UTF-8/LF、Unix 0755、内容/CRC 及不覆盖发布。

所有配置操作均在临时 HOME/CODEX_HOME 中测试，未打开真实 Codex。
Shell 测试使用人工运行时和模拟外部命令；不是对 Mac 二进制的执行测试。
